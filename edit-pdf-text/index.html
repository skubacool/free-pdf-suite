Change the Words, Keep the Look

Click any line of text on the page and a small editor opens with the current words. Retype them, adjust the size, font, weight, alignment or colour if needed, and the page is rebuilt with your text in place of the old.

Under the hood a PDF stores text as separate positioned glyphs rather than a flowing paragraph, so Edit PDF Text erases the old words by rebuilding the paper behind them from the surrounding colours, then paints the new words on top in a matching size and colour. The result looks like the original with the change made.

Good to Know

Pages you edit become images, so their text is no longer selectable; pages you do not touch are copied across unchanged and stay sharp, searchable vector pages. Run the result through OCR if you need selectable text back. Everything happens in your browser, and you can chain this with signing, watermarking and more inside the PDF Workspace.

Edit PDF Text — Frequently Asked Questions

Can I change the text in any PDF?

You can edit any line that contains real text. If the page is a scan (a picture of text) there is nothing to click, so run it through OCR first.

Will the new text match the original font?

It matches the size, weight and colour and picks the closest of sans-serif, serif or monospace. An embedded custom typeface cannot be reused, so it will look similar rather than identical.

What happens to the rest of the document?

Only the pages you change are re-drawn. Every other page is copied across exactly as it was.

Does the file leave my device?

No. Everything runs in your browser. Nothing is uploaded.
