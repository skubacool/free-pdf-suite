An Archive Copy That Looks the Same in Twenty Years

PDF/A is the ISO standard for archiving documents: everything the file needs to display is inside it, with no external fonts, scripts or encryption. Many government, legal and audit workflows ask for it.

This tool renders each page and rebuilds it as a PDF/A-2b page with an sRGB colour profile and matching XMP metadata. The page text is written back as an invisible, fully embedded text layer, so the archive stays searchable and you can still select and copy words.

Good to Know

Because pages are rebuilt as images, the file will not keep original vector graphics, form fields, links or bookmarks, and the size depends on the quality you choose. Check the result with a validator such as veraPDF if your process requires formal proof. Everything runs in your browser; you can also continue in the PDF Workspace.

PDF to PDF/A — Frequently Asked Questions

Which PDF/A level does this produce?

PDF/A-2b, the most widely accepted level for archiving, which guarantees the page looks the same in future.

Will the text stay searchable?

Yes. The text of each page is kept as an invisible embedded text layer, for Latin and Thai text.

What is lost in the conversion?

Original vector graphics, form fields, links and bookmarks. Pages become images so they can meet the strict PDF/A rules reliably.

Does the file leave my device?

No. Everything runs in your browser. Nothing is uploaded.
