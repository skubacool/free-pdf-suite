Build a Form in Minutes

Open your PDF (or start with a blank A4 page), choose a field type and drag on the page where it should go. Rename each field, set a drop-down’s choices, mark a field required, and download.

The fields are real AcroForm fields, so Acrobat, Preview and browsers let people type into them, tick them and choose from lists, and your own software can read the answers back.

Good to Know

Fields use a standard font, which suits Latin text; for forms people will fill in Thai you may prefer to print and write. To fill a finished form, use Fill PDF Form. Everything runs in your browser, and you can chain this with other tools inside the PDF Workspace.

Create Fillable Form — Frequently Asked Questions

Which field types can I add?

Single-line text boxes, multi-line text areas, check boxes, drop-down lists and radio-button groups.

How do radio buttons work?

Give radio buttons the same name and they form one group where only one choice can be selected.

Can I start from nothing?

Yes. Choose “Start with a blank A4 page” and build the form from scratch.

Does the file leave my device?

No. Everything runs in your browser. Nothing is uploaded.
