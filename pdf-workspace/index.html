    A desktop-style PDF editor, without the upload

    Desktop PDF suites let you open a file once and keep working on it: unlock it, fix a page, drop in a signature, add a password, save. Free web tools usually make you download and re-upload between every job. The Workspace fixes that: your PDF is opened once, every tool you use is applied to that same document, and you download the finished file whenever you like.

    Every tool in the rail is one of this site's normal tools with all of its options, so nothing is dumbed down. Use them in any order and as many times as you need; each result is kept as a version, so Undo takes you back one edit at a time.

    How to use it

    1. Drop your PDF (or click to browse). It stays in your browser.
    2. Click a tool in the rail - Rotate, Sign, Watermark, whatever you need. Its panel opens with your document already loaded.
    3. Set the options and press the tool's button. The result is applied to your document straight away; pick the next tool, or run the same one again.
    4. Press Undo if you change your mind, and Download PDF whenever you're done.
    🔒 100% private. Every step runs in your browser - the file is never uploaded, at any stage.

    Frequently asked questions

    Do I have to upload my PDF once for every tool?

    No. Open it once; every tool you use is applied to the same document, so you can rotate, sign, watermark and protect in a row and download one finished PDF.

    Can I use just one tool here?

    Yes. Open the PDF, click the one tool you need, apply it and download - it works exactly like that tool's own page.

    Is anything uploaded to a server?

    No. Every step runs in your browser with JavaScript. Your file never leaves your device, so it is safe for contracts, IDs and bank documents.

    Is there a required order?

    No - use the tools in any order. Two tips: remove a password before anything else, and add a password as your last step, because a protected file cannot be edited further (the workspace warns you if you try).

    Can I undo an edit?

    Yes. Every edit is kept as a version; Undo steps back one at a time, all the way to the original file.

    Why does "Remove password" turn my text into images?

    Browsers cannot decrypt PDF content streams directly, so the unlock step re-renders each page. If you need the text to stay selectable, start from an unlocked copy.
